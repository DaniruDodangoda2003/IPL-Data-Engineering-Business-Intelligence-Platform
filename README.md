# IPL Data Engineering & Business Intelligence Platform

An end-to-end Data Engineering and Business Intelligence solution developed using IPL datasets from 2008–2024.

## Technologies

- SQL Server
- SSIS
- SSAS
- Power BI
- Data Warehousing

## Project Features

- Data extraction and transformation pipelines
- Star schema data warehouse design
- Slowly Changing Dimensions (SCD Type 2)
- OLAP cube development
- Interactive Power BI dashboards
- Business analytics and reporting

## Project Architecture

Data Sources  
↓  
ETL Pipeline (SSIS)  
↓  
Data Warehouse (Star Schema)  
↓  
SSAS OLAP Cube  
↓  
Power BI Dashboard

## Deliverables

- SQL Server Data Warehouse
- SSIS ETL Packages
- SSAS Cube
- Power BI Report
- Documentation
